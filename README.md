# Pocket Distro Alpha

A power-optimized Linux operating system for an ARM-based handheld device
with a touch interface, hot-swap USB peripheral support, and documented battery savings.

## Repositories

| Component | Repository | Language |
|---|---|---|
| OS and Build System | https://github.com/pda-capstone/os | Shell, Nix, APKBUILD |
| Wayland Touch UI | https://github.com/pda-capstone/ui | Python, GTK4 |
| Hot-Swap Daemon | https://github.com/pda-capstone/daemon | C |
| Power Measurement | https://github.com/pda-capstone/power | Python |
